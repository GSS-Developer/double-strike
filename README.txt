DOUBLE STRIKE 公開用セット

GitHubで新しい公開リポジトリ double-strike を作り、このフォルダ内のファイルをアップロードしてください。Settings > Pages > Deploy from a branch > main / (root) > Save。
公開URL例: https://USERNAME.github.io/double-strike/

重要: index.html内の og:image の USERNAME を自分のGitHubユーザー名に置換すると、LINEの画像プレビューが正しく表示されます。LINEのプレビュー表示はLINE側の仕様・キャッシュに依存します。
